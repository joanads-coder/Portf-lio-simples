# Portfólio simples

Site pessoal desenvolvido com HTML e CSS puro, como projeto acadêmico.

O site apresenta uma página com seções de introdução, sobre mim, habilidades, 
projetos e contato, com um layout organizado e responsivo.

## Tecnologias utilizadas
- HTML5
- CSS3

## Como visualizar
Basta abrir o arquivo `index.html` no navegador, ou acessar o site publicado 
pelo GitHub Pages (se disponível).
